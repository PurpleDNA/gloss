# Store screenshots

Save captures **here**, committed to the repo — unlike `store/assets/`, these
cannot be regenerated.

**Specs:** PNG, exactly **1280×800** (or 640×400). 1–10 images. Edge and Chrome
both accept these dimensions.

**Naming** — the store orders by filename, and the first is what most people
judge the listing on:

```
01-core-loop.png       Article open, term highlighted, panel showing an explanation
02-follow-up.png       Same panel, two or three exchanges deep
03-providers.png       Settings provider grid, free-tier badges visible
04-history.png         History list with entries and a search term typed
05-dark-mode.png       Any of the above in dark theme
```

Use a neutral, non-sensitive page. Reviewers look at these, and a screenshot of
a private dashboard invites questions.

**Capturing at exact size:** open DevTools, press Ctrl+Shift+M for device
toolbar, set a custom 1280×800 viewport, then use the DevTools menu →
"Capture screenshot".
